戾煞配平助手 0.7.0 · 团长测试版

完整解压后打开 LishaOverlay.exe，保留同目录的 _internal 文件夹。

1. 框住完整25格，点第二行的网格图标定位格子并识别心法，有疑问时只需补认列出的格子。准备后点 ▶ 开始识别。
   拖动标题旁的空白区可移动控制条。开始后扫描框锁定，停止后可调整。
   点击标题旁的“？”可查看版本和作者信息。
2. 点“标T”，再点团框中的承伤者。选中的格子会显示金色T。手动“扇+圈”默认预演一式给主T加三层赤，已有两层时提示“换T，要炸”。可右键改为“一式后”。“仅圈”按团框现状计算。
   “自动阶段”默认开启，从团框首次出现机制Buff估时，扇形落地后切换到“仅圈”，进入三圈后收起指挥，团框清空后等待下一轮。点第一行的“手动/自动”切换，也可以直接点“扇+圈”或“仅圈”手动接管。
   状态区右侧显示处理后的红黑人数和差值。下方左侧是指挥口令，长句会换行。右侧是煞气圆标和人数。引导和蹭圈按扇形后的层数显示。团框红扇和数字黑圈标出具体执行的人，亮边黑圈是引导者。
3. 第一行“普通/英雄”切换难度并保存选择，初始为普通。普通人数差0～2安全、3～4危险、5及以上死，英雄0～1安全、2危险、3及以上死。差值正数红色、负数和零黑色，旁边用绿色对勾、橙黄色“危”、红色“死”提示风险。“3+”汇总三层及以上人数。
   点第一行的“正平/简操”切换策略。简操优先好念、好执行的安全方案，正平优先缩小红黑人数差。两种模式都尽量把口令缩到三组，优先考虑远程和治疗出去引导。
   换人或换位后，可右键重新识别心法或核对名单。
4. 引导1主点、2单走、3旁点。双圈站主点与旁点的交集，三圈使用三角交集。具体格子上的红扇、黑圈数字为实际分配。
5. 边框、控制条和标记可出现在桌面截图、录屏和远程桌面。识别取图瞬间只短暂隐藏标记层，边框与控制条保持显示。预览窗口请放在扫描框之外。
6. 录屏建议选择“显示器/桌面采集”并包含悬浮窗口。部分录屏软件的“游戏采集”只采集游戏，其他程序的悬浮层可能不会被录入。
7. 反馈问题时，右键面板或托盘选择“导出调试包”，ZIP保存在桌面。也可双击同目录“导出调试包.cmd”。调试包包含环境信息、日志和识别/策略记录。需要图片时，用 LishaOverlay.exe --debug-captures 启动并复现问题，再导出，包内会加入最近的框内原图、标记图和Buff裁片。分享前检查游戏画面。

日志目录为 %LOCALAPPDATA%\LishaBalancer。调试图片按最近一次覆盖保存，记录有容量限制。
支持窗口化或无边框游戏。死亡、已有隔绝和四层状态使用后备求解，并显示“参考”。
