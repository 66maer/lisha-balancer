戾煞配平助手 0.6.0 · 团长测试版

完整解压后打开 LishaOverlay.exe，保留同目录的 _internal 文件夹。

1. 框住完整25格，点网格图标校准，再点 ▶。开始前可移动、缩放，开始后锁定，停止后恢复。
   点击标题旁的“？”可查看版本和作者信息。
2. 扇＋圈 / 仅圈独立计算。面板固定为两行状态、三行指挥，状态区右侧显示处理后的红黑人数和差值。三行口令依次显示吃扇、引导圈、蹭圈，单圈和双圈等合并在第三行。
3. 控制行“普/英”切换难度并保存选择，初始为普通。普通人数差0～2安全、3～4危险、5及以上死，英雄0～1安全、2危险、3及以上死。差值正数红色、负数和零黑色，旁边用绿色对勾、橙黄色“危”、红色“死”提示风险。“3+”汇总三层及以上人数。
   求解优先避开三圈和双圈，再考虑参与人数和队伍位置，圈组按扇形后的Buff分配。按队伍位置优先安排1、2队，其次3、4队，5队最后候补。右键面板可选择“正平优先”，在已验证人数范围内选择更接近正平的方案。
4. 引导1主点、2单走、3旁点。双圈站主点与旁点的交集，三圈使用三角交集。具体格子上的红扇、黑圈数字为实际分配。
5. 边框、控制条和标记可出现在桌面截图、录屏和远程桌面。识别取图瞬间只短暂隐藏标记层，边框与控制条保持显示。预览窗口请放在扫描框之外。
6. 录屏建议选择“显示器/桌面采集”并包含悬浮窗口。部分录屏软件的“游戏采集”只采集游戏，其他程序的悬浮层可能不会被录入。
7. 反馈问题时，右键面板或托盘选择“导出调试包”，ZIP保存在桌面。也可双击同目录“导出调试包.cmd”。调试包包含环境信息、日志和识别/策略记录。需要图片时，用 LishaOverlay.exe --debug-captures 启动并复现问题，再导出，包内会加入最近的框内原图、标记图和Buff裁片。分享前检查游戏画面。

日志目录为 %LOCALAPPDATA%\LishaBalancer。调试图片按最近一次覆盖保存，记录有容量限制。
支持窗口化或无边框游戏。死亡、已有隔绝和四层状态使用后备求解，并显示“参考”。
